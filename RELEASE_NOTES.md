# v0.13.0

## Совместимость

- **SBG 0.6.2** — скрипт запускается без подтверждения при каждом старте.

## Улучшения

- **Ограничения рисования.** Режим «звезда» переключается без возврата к опорной точке: повторный клик кнопки в попапе или новая кнопка-переключатель на карте. В тосты режима звезды и назначения центра добавлено имя точки.
- **Улучшенный UI попапа точки.** Подкраска активных нативных кнопок: звёздочка золотом, замочек синим. Сама игра только меняет иконку (filled/outline), цвет не подкрашивает.

## Багфиксы

- **Улучшенный UI попапа точки.** Нативные иконки звёздочки и замочка в попапе корректно обновляются при клике (раньше на SBG 0.6.2 оставались с прошлым состоянием из-за конфликта с дублирующими кнопками SVP — теперь убраны).
