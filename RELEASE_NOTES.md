# v0.14.0

## Совместимость

- **SBG 0.7.0** - скрипт запускается без подтверждения. Версия 0.6.2 тоже остаётся поддержанной.
- Язык интерфейса скрипта снова совпадает с языком игры у игрока, который ни разу не заходил в настройки игры.

## Новое

- **Версия скрипта на загрузочном экране** - рядом с версией игры показывается версия Vanilla+: `Stock/0.7.0, VanillaPlus/0.14.0`. Пригодится в баг-репортах.

## Багфиксы

- **Инструменты рисования** - пока выбран инструмент, клик по карте принадлежит ему и не открывает попап точки. Перетаскивание вершины в режиме правки не поворачивает карту, закрытие тулбара кнопкой на карте снимает инструмент, а в режиме удаления фигура снимается только по клику рядом с ней.
- Диалог о непроверенной версии игры показывается на языке игры - раньше был только на русском.
- Конфигурация CUI, которую скрипт заводит в общей базе избранного, больше не выбеливает карту в тёмной теме: учтены системная тема и тёмные тайлы CartoDB. Заметно при установке CUI после Vanilla+.
