# Локальная разработка: установка сборок

`npm run local:serve` запускает сервер со ссылками на готовые userscript-файлы:
`http://127.0.0.1:5175/`. Сборку запускают отдельно.

Режимы debug/watch, загрузчик [LOCAL] и каталоги `dist/release/` / `dist/debug/`
добавлены в [PR #53](https://github.com/wrager/sbg-vanilla-plus/pull/53).
Перед использованием этого сценария они должны быть в вашей ветке.
Сервер не добавляет эти режимы и не меняет конфигурацию Vite.

## Подготовка

Нужны Node.js 24 LTS, npm, Chrome и Tampermonkey. Выполните `npm ci`.
Глобальная установка Vite или TypeScript не нужна.
В PowerShell можно использовать `npm.cmd`, если запуск `npm.ps1` ограничен политикой
выполнения; менять политику Windows для этого не требуется.

## Установка

1. В настройках расширения Tampermonkey разрешите выполнение пользовательских
   скриптов: `Allow User Scripts` в поддерживающем его Chrome.
2. Для загрузчика [LOCAL] разрешите `Allow access to file URLs`.
3. Запустите `npm run dev:watch` и дождитесь первой сборки.
4. В другом терминале запустите `npm run local:serve`.
5. Откройте `http://127.0.0.1:5175/`, выберите локальный загрузчик [LOCAL]
   и проверьте его содержимое перед установкой в Tampermonkey.
6. Оставьте включённым один вариант SVP. После сохранения исходников дождитесь
   сборки и вручную обновите страницу игры.

Официальные инструкции Tampermonkey:
[разрешение userscript](https://www.tampermonkey.net/faq.php?q=Q209) и
[доступ к локальному файлу](https://www.tampermonkey.net/faq.php?q=Q402).

Ссылки сервера:

| URL                | Готовый файл                                | Команда сборки        |
| ------------------ | ------------------------------------------- | --------------------- |
| `/release.user.js` | `dist/release/sbg-vanilla-plus.user.js`     | `npm run build`       |
| `/debug.user.js`   | `dist/debug/sbg-vanilla-plus.user.js`       | `npm run build:debug` |
| `/local.user.js`   | `dist/debug/sbg-vanilla-plus.local.user.js` | `npm run dev:watch`   |

Если файл отсутствует, сервер отвечает 404 и показывает команду сборки.
Старые файлы непосредственно в `dist/` не используются.

[DEBUG] — самостоятельный снимок сборки: после изменений его нужно установить
заново. [LOCAL] содержит `@require file:///...` и перечитывает debug-файл
при следующей загрузке страницы. После изменения метаданных или переноса клона
пересоберите debug и переустановите загрузчик. Сервер можно остановить после установки.

## Ранний запуск

Для ранних перехватов SVP на `document-start` предпочтителен полный release/debug
бандл. [DEV] загружает модули асинхронно, а `@require` в [LOCAL] может задержать
запуск: порядок нужно проверить в конкретном браузере. Если перехват опаздывает,
используйте самостоятельный [DEBUG] или релиз.

## Работа сервера

Сервер привязан к `127.0.0.1:5175`. Разрешены только главная страница и три
перечисленных пути, методы GET/HEAD. POST и другие методы получают 405,
произвольные пути — 404. Ответы не кешируются; каждый запрос читает текущий файл.

Сервер не открывает браузер, не обновляет игру и не выполняет сборку.
Занятый порт приводит к ошибке, другой порт автоматически не выбирается.
Для остановки нажмите Ctrl+C.

## Проверки

`npm run test:local-server` проверяет сервер на loopback с временными файлами:
GET/HEAD всех сборок, обновление файла, отсутствие сборки, ошибки чтения,
отклонение произвольных путей и записи, отказ CLI при занятом порте.
Эта команда включена в CI; игра и аккаунт для тестов не нужны.

Полный набор проверок приведён в [AGENTS.md](../AGENTS.md).
`npm run test:build` из #53 отдельно проверяет бандлы, metadata, source maps и watch.
Успешные тесты не заменяют проверку разрешений конкретного профиля Tampermonkey.
