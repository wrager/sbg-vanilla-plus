## Общие инструкции

[AGENTS.md](../../AGENTS.md) — точка входа: порядок чтения документов, проверки и каталог
скиллов. [CLAUDE.md](../../CLAUDE.md) импортирует его через `@AGENTS.md`. Специфические
правила проекта добавляй в `docs/agent/rules.md`, чтобы они применялись в обоих агентах.

## Скиллы для Codex и Claude Code

Для разработки установи зависимости через `npm ci`; полный список проверок — в
[AGENTS.md](../../AGENTS.md). Если в Windows-песочнице Jest не может записать кэш
в `%TEMP%` (`EPERM` при переименовании файлов), запусти
`npm run test -- --runInBand --cacheDirectory node_modules/.cache/jest`.
Это тот же набор тестов с последовательным запуском и кэшем внутри игнорируемого
`node_modules/`.

| Задача         | Codex                             | Claude Code                       | Прежняя команда Claude/Cursor |
| -------------- | --------------------------------- | --------------------------------- | ----------------------------- |
| Новый модуль   | `$my-sbg-new-module keepScreenOn` | `/my-sbg-new-module keepScreenOn` | `/new-module keepScreenOn`    |
| Релиз          | `$my-sbg-release 0.2.0`           | `/my-sbg-release 0.2.0`           | `/release 0.2.0`              |
| Анонс с версии | `$my-sbg-announce 0.2.0`          | `/my-sbg-announce 0.2.0`          | `/announce 0.2.0`             |

Команды вводятся в чате агента, не в терминале. Для нового модуля добавляй описание
желаемого поведения. Можно сформулировать задачу обычным текстом: описания скиллов
позволяют агенту выбрать нужный сценарий. Релиз создаёт локальный коммит и тег без push;
анонс возвращает текст без публикации.

### Один источник, две папки обнаружения

- `.agents/skills/<name>/SKILL.md` — исходник, который читает Codex.
- `.claude/skills/<name>/SKILL.md` — создаваемая скриптом копия для Claude Code.
- `docs/agent/*.md` — сами сценарии; скиллы ссылаются на них, а не дублируют.
- `.claude/commands/*.md` — сохранённые короткие команды, ведущие к тем же скиллам.
- `.cursor/commands/*.md` — существующие команды Cursor, ведущие к общим сценариям.

Обе папки скиллов хранятся в Git. После клонирования не нужны установка в домашний
каталог, симлинки, junction или права администратора Windows. Глобальные настройки
агентов и репозиторий `ai-config` для этой схемы менять не требуется.

Имена имеют префикс `my-sbg-`: `my-` соответствует пользовательскому соглашению,
а `sbg-` отличает проектные скиллы от личных скиллов других проектов.
Относительные ссылки `../../../docs/agent/...` работают из обеих папок скиллов.

### Обновление или добавление скилла

1. Измени сценарий в `docs/agent/` и при необходимости исходник в `.agents/skills/`.
   Для нового скилла создай папку `my-sbg-<name>` с `SKILL.md`, YAML-полями `name`
   (совпадает с именем папки), `description` и инструкциями. Общий формат ограничен
   этими полями; не переноси в него специфические для Claude настройки инструментов.
2. Выполни `npm run skills:sync`. Скрипт копирует весь каталог скилла, включая
   `scripts/`, `references/` и `assets/`, если они нужны. Копии вручную не редактируй.
3. Выполни `npm run skills:check`. Команда проверяет соответствие всех файлов и запускает
   тесты синхронизации; она также входит в CI. Форматирование проверяет обычный
   `npm run format:check`.
4. Добавь в коммит исходники, копии и изменённые сценарии. После добавления скилла
   открой новую сессию агента, если текущая ещё не показывает его в списке.

`skills:check` ничего не записывает. `skills:sync` обновляет только отличающиеся или
отсутствующие копии. Если файл существует только в `.claude/skills/`, обе команды
останавливаются до записи: перенеси нужные изменения в исходники или явно удали
устаревшую копию. При удалении скилла удаляй его из обеих папок. Симлинки не поддерживаются.

Скрипт использует только Node.js (20+, как в CI), не требует новых npm-зависимостей
и находит корень относительно собственного файла, независимо от текущего каталога.

### Основания совместимости

- [OpenAI: локальные скиллы Codex](https://learn.chatgpt.com/docs/build-skills) — обнаружение в `.agents/skills/`.
- [Claude Code: skills](https://code.claude.com/docs/en/skills) — проектные скиллы в `.claude/skills/`.
- [Claude Code: общие инструкции](https://code.claude.com/docs/en/memory#share-one-file-with-other-coding-tools) — импорт `@AGENTS.md`, в том числе для Windows.
