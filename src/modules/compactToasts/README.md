# compactToasts

Собирает одновременные уведомления в один блок в левом верхнем углу.

## Что видит игрок

Без модуля каждое сообщение игры - отдельный тост. Серия действий, прежде всего рисование линий, засыпает экран: отказы сервера приходят сверху по центру, сообщения о новых регионах - сверху справа, а про обычную проведённую линию игра не пишет вовсе.

С модулем всё это - один блок:

```
Регионы: +2 (1.4 км2)
Недостаточно ключей (x3)
Точка вне зоны действия
```

Повтор сообщения увеличивает счётчик, а не добавляет строку. Блок живёт, пока идут сообщения: каждое новое продлевает его на обычные для игры 3 секунды. Если хотя бы одна строка - отказ, блок красный целиком.

## Граница: что в блок не попадает

Тосты, привязанные к элементу (попап точки, инвентарь, профиль, уведомления), проходят мимо блока нетронутыми.

Это не упрощение, а требование игрового кода: тост с добычей игра создаёт пустым и дописывает содержимое уже после показа (`refs/game/script.js:830-845`). Подмена такого узла стёрла бы игроку список добычи. Заодно такие тосты стоят у своего элемента и в общую стопку не лезут - собирать их незачем.

## Короткая строка про регионы

Замкнув регион, игрок получает трёхстрочное сообщение (`popups.new-regions`, `refs/game/script.js:1753`):

```
Новые регионы: 3
Общая площадь: 1.4 км2
Макс. площадь: 0.7 км2
```

Три строки на одно событие вытесняют из блока всё остальное, поэтому тост сворачивается в одну: `Регионы: +3 (1.4 км2)`.

Узнаётся он по шаблону из локализации игры (`i18next.getResource`), слово для подписи берётся оттуда же (`info.regions`), а площадь переиспользуется уже отформатированной игрой. Поэтому строка совпадает по языку и единицам измерения с остальным интерфейсом, а `regionsLine.ts` не содержит собственных переводов.

Шаблон кэшируется вместе с языком: игрок может сменить язык игры без перезагрузки страницы.

## Отвергнутые подходы

**Чтение ответов сервера.** Дало бы точный счёт проведённых линий, но это второй источник истины к тому, что игра и так рисует, плюс лишний перехват сети. Про обычные успешные линковки решено не писать вовсе, а всё остальное есть в самих тостах.

**Метка в исходнике игры.** По параметрам тост линковки неотличим от любого другого: ошибка приходит из общего `apiSend` без опций тоста, то есть с теми же `error-toast`, `selector: null`, `top center`, что и ошибки `self`, `inventory`, `point`, `attack2`. Пометить его можно было бы патчем скрипта игры (`core/gameScriptPatcher.ts`), но литеральный якорь патча ломается от любой правки рядом, а для опознания достаточно данных, которые игра публикует сама. Поэтому блок собирает все экранные тосты, а локализация используется только там, где текст надо укоротить.

**Обрезка по длине.** Оборванная многоточием фраза хуже длинной: игрок не понимает, что потерял. Не распознали сообщение - показываем целиком.

## Использование Toastify

Модуль патчит `Toastify.prototype.showToast` - единственную точку, через которую проходят все уведомления игры. Инстансы не создаёт, а меняет входящий, поэтому учёт `popup_toasts` внутри игры остаётся согласованным.

Опора на внутренности библиотеки (сверено по `refs/toastify/toastify.js`, версия 1.12.0):

| Что                                                               | Зачем                                                           |
| ----------------------------------------------------------------- | --------------------------------------------------------------- |
| `options.position` хранится сырым и читается в `buildToast` (:64) | позицию блока можно поменять у готового инстанса                |
| `options.className` подставляется конкатенацией (:64)             | класс ошибки проверяется по токену, а не равенством строки      |
| `toastElement.timeOutValue` (:105)                                | снять таймер прежнего узла                                      |
| `removeElement` откладывает удаление на 400 мс (:112)             | прежний узел снимаем напрямую, иначе два блока висели бы вместе |
| `Toastify.reposition()` при показе (:105, :117)                   | раскладку по вертикали считает библиотека, своей у SVP нет      |
