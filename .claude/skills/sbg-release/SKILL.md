---
name: sbg-release
description: Подготовить SBG Vanilla Plus к релизу через существующий release PR и сопровождать выпуск с отдельным подтверждением внешних действий.
---

Прочитать AGENTS.md и [общий процесс релиза](../../../docs/releasing.md).
Сначала выполнить `node scripts/releaseNotes.mjs inspect` и использовать найденный release PR.
Комментарий хранит черновые notes и подтверждения; финальный источник - блок notes
в описании PR по общему процессу. Прочитать полные сообщения коммитов, итоговый код
и обсуждения PR по [правилам текста](../../../docs/agent/release.md).
Показать проект notes и дать пользователю отредактировать его. После редактуры
проверить формулировки и показать полное описание PR с подписью.
Перед публикацией текста, правкой PR, запуском Prepare release и merge получить
отдельное явное подтверждение конкретного действия. Подтверждение плана его не заменяет.
Соблюдать правила проверки текста и все границы разрешённых внешних действий.
Подготовка не разрешает merge, тег или публикацию.
Не создавать локальные теги; опубликованные теги и assets не переписывать.
Не поручать пользователю команды и действия в GitHub, доступные агенту.
Запрет взаимодействия агента с живой игрой остаётся в силе.

После обновления PR ботом проверить финальный блок, версию, диапазон и материалы.
При перезаписи notes восстановить и согласовать текст, затем повторить подготовку;
отдельную блокировку Release Please не добавлять. Генерируемые файлы notes вручную не править.

Изменения процесса и скиллов выносить в отдельный PR и дождаться его вливания
до подготовки релиза. Развивать скилл по проверенным решениям, не превращая его
в журнал релиза или копию общего процесса. Менять исходники `.agents/skills/`,
запускать `npm run skills:sync`, читать diff копий Claude и проверять синхронизацию.
