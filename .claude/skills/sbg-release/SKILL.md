name: sbg-release
description: Подготовить существующий release PR SBG Vanilla Plus от Release Please с проверенными русскими release notes и локальным коммитом, без merge и публикации.
---

Прочитай [AGENTS.md](../../../AGENTS.md) и указанные там правила проекта.
Выполни [сценарий подготовки release PR](../../../docs/agent/release.md).
Пути и команды считаются от корня репозитория.

Версию бери из существующего release PR бота, не запрашивай её для ручного bump.
Сохрани служебное тело PR, заголовок и метки Release Please.
Результат — проверенные notes в той же ветке и локальный коммит.
По умолчанию не пушить; push выполнять, если он входит в запрос пользователя.
Не создавать локальный тег и не выполнять merge или публикацию в рамках подготовки.
Запрос на выпуск обрабатывается отдельно по [процессу релизов](../../../docs/releasing.md).
